# Block Puzzle

Головоломка с блоками для Android на Godot 4.7: поле 8×8, три фигуры в лотке, заполненные ряды и колонки очищаются. Вокруг игры — уровни и Battle Pass, монеты и бонусы, ежедневные награды, профиль с аватарками и рамками, темы оформления и достижения.

## Устройство проекта

```
core/                 Чистая логика без узлов — её можно тестировать отдельно
  board.gd            Модель поля 8×8: постановка, поиск и очистка линий
  shapes.gd           Библиотека из 30 фигур
  piece_generator.gd  Наборы фигур: веса по размеру, сложность, гарантия хода
  scoring.gd          Очки за ход: клетки, линии, серия, чистое поле

autoload/             Глобальные системы (Проект → Настройки → Автозагрузка)
  items_db.gd         ItemsDB: цвета, аватарки, рамки и условия их открытия
  events.gd           Events: шина событий партии
  game_settings.gd    GameSettings: звук, музыка, вибрация
  theme_manager.gd    ThemeManager: темы блоков, текущая тема
  progression.gd      Progression: уровень, монеты, статистика, открытые предметы
  achievements.gd     Achievements: достижения со ступенями

themes/               Темы оформления
  block_theme.gd      Ресурс темы (class BlockTheme)
  block_renderer.gd   Отрисовка поля и блоков в стиле темы
  classic/            «Классика»
  space/              «Космос» + анимированный фон

ui/                   Тема интерфейса и превью тем для профиля
game.gd / game.tscn   Главная сцена: контроллер партии
grid.gd               Вид поля (рисует Board)
block.gd              Фигура в лотке (перетаскивание)
profile.gd            Профиль и кастомизация
assets/avatars        Аватарки (SVG), assets/frames — рамки
tools/make_avatars.py Генератор аватарок и рамок в SVG
tests/test_core.gd    Тесты логики
docs/                 План развития и инструкции по контенту
```

## Как это связано

`Game` ведёт партию: берёт набор фигур у `PieceGenerator`, ставит фигуру в `Board`, считает очки через `Scoring` и сообщает о событиях в `Events`. `Progression` и `Achievements` слушают события и сами обновляют статистику, выдают награды и открывают предметы. Цвета и вид блоков берутся из текущей темы `ThemeManager`, поэтому новая тема — это новый файл `.tres`, без правок кода игры.

## Запуск тестов

Один раз откройте проект в редакторе (или выполните `godot --headless --path . --import`), затем:

```
godot --headless --path . -s tests/test_core.gd
```

## Сборка под Android

Project → Export → Android. Нужны шаблоны экспорта Godot 4.7, в разрешениях экспорта включите **VIBRATE** (иначе вибрация не работает). С 31 августа 2026 Google Play требует target API 36 (Android 16) для новых приложений и обновлений.

Подробнее: [docs/ROADMAP.md](docs/ROADMAP.md) — исследование и план, [docs/CONTENT.md](docs/CONTENT.md) — как добавлять темы, аватарки и достижения.
